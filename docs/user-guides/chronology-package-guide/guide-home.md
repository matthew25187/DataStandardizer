# DataStandardizer.Chronology package

Support for chronology-related data standards.

## tz database

### Features

- TZ Database

    Supports the TZ Database for standardized timezone names

- Unix time

    Supports use of Unix time with conversion to and from standard date & time values

- Wide runtime support

    Supports .Net Standard 1.x and 2.0 for use in legacy applications, as well as in-support modern .Net runtimes.
