# Concepts

These articles explain *how* Data Standardizer is designed and *why*, so the
patterns you meet in the per-package guides make sense.

## In this section

- [Why standardize data](why-standardize-data.md) — the problem strongly-typed
  standards solve.
- [Strongly-typed codes](strongly-typed-codes.md) — the enum / `IStringEnum`
  struct pattern used across the packages, and the shared `Core` building blocks.
- [Metadata and lookups](metadata-and-lookups.md) — how names, numeric codes,
  and other attributes are attached to code members and retrieved.
- [Data currency and versioning](data-currency-and-versioning.md) — how the
  code lists are kept up to date with the standards bodies.
