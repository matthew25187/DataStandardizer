# DataStandardizer.Communication package

Support for communication-related data standards.

## Features

- Comprehensive support for ITU-T E.164

    Adds a type for international numbers for geographic areas, global services, networks, groups of countries, and trials.  Supports parsing numbers from strings and use of lists of active codes issued by the ITU.
    
- Wide runtime support

    Supports .Net Standard 1.x and 2.0 for use in legacy applications, as well as in-support modern .Net runtimes.
