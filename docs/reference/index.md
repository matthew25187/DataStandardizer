# Reference

Lookup material for when you already know the package and just need the details.

- **Per-package API** — each package has an **API reference** that documents its
  public types, one page per type; see [Packages](../packages/index.md).
- **Code lists** — the standardised codes (currencies, countries, subdivisions,
  languages, scripts, time zones, and so on) are documented as the **Fields** of
  their code type's reference page — for example
  [Iso4217CurrencyCurrent](../packages/money/reference/Iso4217CurrencyCurrent.md).
  See [Data currency and versioning](../concepts/data-currency-and-versioning.md)
  for how those code lists are produced.
- [Glossary](glossary.md) — definitions of the standards and domain terms used
  throughout the documentation.
