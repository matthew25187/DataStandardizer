# ItuE164AssignedCountryCodesForGeographicAreas Enum

## Definition

The ITU E.164 country codes assigned for geographic areas. Each member corresponds
to a specific country or geographic area and its E.164 country code. Used as the
country-code argument of
`ItuE164InternationalNumber.CreateNumberForGeographicArea`.
