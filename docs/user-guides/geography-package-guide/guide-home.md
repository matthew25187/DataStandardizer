# DataStandardizer.Geography package

Support for geography-related data standards.

## Features

- Comprehensive support for ISO 3166

    - **ISO 3166-1, *Codes for the representation of names of countries and their subdivisions – Part 1: Country code***

        - Alpha-2 codes
        - Alpha-3 codes
        - Numeric codes

    - **ISO 3166-2, *Codes for the representation of names of countries and their subdivisions – Part 2: Country subdivision code***

- Supports **UN M49, *Standard Country or Area Codes for Statistical Use (Series M, No. 49)***

- Wide runtime support

    Supports .Net Standard 1.x and 2.0 for use in legacy applications, as well as in-support modern .Net runtimes.
